# Emberwish

A tiny desktop ritual app. Light incense, make a wish, and let it burn quietly while you work.

> For peaceful desktops and uneventful deployments.

## Development

Execution-mode development is proceeding in coherent phases under Agent Continuity v0.3.4. Implementation work lives on a development branch until its verification and review gates are satisfied. This repository is being bootstrapped; there is no verified desktop release yet.

The app is visual-only: it does not read repositories, run deployment commands, request credentials, or claim to change deployment outcomes.
